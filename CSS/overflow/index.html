Notes

  1. Overflow occurs when children doesn't fit the parents dimensions
  2. Overflow property acceptes - visible, hidden, clip, scroll, auto
  3. visible: is the default, which makes the content overflow the parent, no scrollbar displayed.
  4. hidden: hides the content which overflows parents dimensions
  5. clip: clips the overflowed children content and also prevents scrollbars programatically.
  6. scroll: always displays the scrollbar whether content overflows or not.
  7. auto: displays scrollbar when content overflows else doesn't display scrollbar.
